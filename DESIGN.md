# CKD Launch Intelligence Dashboard Direction

## Direction contract

This is an Operate-mode evidence workbench for analytics leaders and hiring reviewers. The visual language is a restrained clinical-review ledger: warm paper-white content, ink-black type, deep indigo navigation, and restrained signal colors reserved for evidence strength and state. The material is the audit trail, not a decorative medical metaphor.

### First viewport

The summary opens with the decision sentence “What can this evidence support?” followed by three evidence-backed findings, a source boundary strip, and a compact “review path” navigation. Each finding shows source population, grain, denominator, uncertainty, and a direct link to its supporting view.

### Visitor path

Summary → Patient need → Patient finding → Care & prescribing → Trials → Opportunity → Synthetic journeys. A persistent left rail collapses to a horizontal select/navigation control on narrow screens. Every page repeats a compact evidence header so a reviewer can enter from a deep link without losing context.

### Signature interaction

The evidence drawer toggles between “Decision readout” and “Method notes” without hiding the result. Charts always have a “View as table” equivalent, and empty/error/loading states use the same space and hierarchy as real results.

### Cross-surface reach

Shared page header, source/evidence chip, limitation callout, chart/table pair, metric row, and boundary banner are reused across every page. Synthetic and scenario-only views use explicit banners instead of color alone.

### Honest risk

The dashboard could look more definitive than the underlying evidence. Counter this by showing denominator, uncertainty, evidence type, source grain, provenance, and limitations adjacent to every finding; never collapse incompatible source geography into a rank.

### Accessibility contract

Use semantic headings and landmarks, visible keyboard focus, 4.5:1 body contrast, state text in addition to color, responsive tables with captions, and chart alternatives that preserve the same values and labels.
